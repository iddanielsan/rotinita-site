# Demonstração de rotina

`minha-manha.webp` mostra “Minha manhã” com Acordar, Vestir e Sair.
É uma captura demonstrativa de componentes Flutter com repositórios e dados
fictícios, não uma captura de conta familiar ou prova de resultado clínico.
A página mantém essa identificação visível.

Fonte no workspace: `tea-app/design-assets/app-store/source/routine-phone.png`.
Proveniência e helper de captura: `tea-app/design-assets/app-store/README.md`.
Exportação publicada: WebP, 516 × 1200, qualidade 88, sem recortar ou alterar
os controles. Não substituir por dados/imagens de crianças reais.
